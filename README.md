# 宇宙玻璃 Studio 3D

- `index.html`：按平面圖尺寸（室內 11.9 m × 3.85 m）建立的 Studio 立體模型，可旋轉並切換四種設計風格。
- `planner/`：裝修 3D 規劃工具。輸入面積同樓底高度、揀地板牆身質感、擺水電位同電器傢俬，3D 即時更新；可以上傳自己嘅平面圖（圖片或 PDF）做底圖，校正比例之後照住描牆。

開啟 GitHub Pages 之後：

- Studio 模型：`https://fiveathree.github.io/catstrangestudio/`
- 規劃工具：`https://fiveathree.github.io/catstrangestudio/planner/`

規劃工具嘅設計只會存喺自己個瀏覽器，可以用「儲存檔案」匯出 `.json` 再傳俾人開。

`planner/vendor/` 內嘅 three.js 同 pdf.js 係第三方程式庫（分別為 MIT 同 Apache-2.0 授權）。
